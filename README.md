# 슈퍼알까기 카드 스튜디오

슈퍼알까기 게임용 카드 이미지를 만드는 도구입니다.

- **① 프레임 · 아이콘**: C·B·A·S·SS 등급 프레임과 역할 아이콘(공격·방어·교란·지원·왕)을 직접 그리거나 AI로 만들어 등록
- **② 이미지 생성**: 등급·스킬·컨셉으로 카드 그림을 대기열에서 여러 장 생성, 편집, 알 텍스처 생성
- **③ 보관함**: 저장한 그림 관리
- **④ 조합하기**: 프레임 + 그림 + 아이콘 + 이름을 조합해 PNG로 받기

## 실행

1. [Python 3](https://www.python.org/downloads/) 설치 (설치할 때 "Add python.exe to PATH" 체크)
2. `start.bat` 더블클릭 → 브라우저에서 `http://localhost:8765` 가 열립니다
   - 직접 실행하려면: `python server.py`
3. ② 이미지 생성 › API 키 설정에 키 입력
   - 🍌 나노바나나: Google AI Studio 키(`AIza…`) 또는 Vertex AI 키(`AQ.…`)
   - 🤖 GPT Image: OpenAI 키(`sk-…`)

## 데이터

작업한 내용은 모두 **`data/` 폴더**에 파일로 저장됩니다. 그래서 git 커밋이나 폴더 복사에 함께 포함됩니다.

| 위치 | 내용 |
|---|---|
| `data/arts/` | 보관함 그림, 알 텍스처 |
| `data/frameGroups/` | 등록한 프레임 그룹 |
| `data/iconSets/` | 등록한 역할 아이콘 세트 |
| `data/settings.json` | 생성 옵션, 조합 배치·글꼴 등 설정 |

- **API 키는 파일에 저장하지 않습니다.** 브라우저에만 저장되므로, 다른 컴퓨터에서는 키를 다시 입력하세요.
- 반드시 `start.bat`(로컬 서버)로 열어야 `data/` 폴더에 저장됩니다. `index.html`을 직접 열면 그 브라우저 안에만 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `render.js` | 프레임·아이콘·내장 그림 엔진·카드 조합 |
| `ai.js` | 나노바나나·GPT 호출, 초록 배경 제거, AI 프레임·아이콘·알 텍스처 |
| `app.js` | 대기열·보관함·조합·저장소 |
| `server.py` | 로컬 서버 (API 중계 + data/ 폴더 저장) |
| `start.bat` | 실행용 |
